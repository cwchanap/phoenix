# HPA-264 — Target-Driven Farming Action Design

**Linear:** https://linear.app/cwchanap/issue/HPA-264/gameplay-polish-make-space-pick-the-farming-action-from-the-target  
**Repository:** cwchanap/phoenix (Godot 4.7.1 / typed GDScript)  
**Delivery:** design review first, then implementation and validation on this *same* draft PR.  
**Dependency:** HPA-353 completed; SessionStateValidator now owns persisted-state checks.  
**Status:** planning proposal; no runtime code changed in this document commit.

## Product decision

Press Space on a farm cell to do the obvious next thing. The selected *seed kind*, not a selected *tool*, is the only farming choice. On an untilled farm cell: Hoe. On tilled, crop-free soil: plant selected seed. On a growing crop: Water. On a mature crop: Harvest. Do not auto-switch to another seed if the chosen kind has no stock.

| Target state | Resolved FarmingAction | Successful code | Blocked examples |
| --- | --- | --- | --- |
| Untilled farm tile | HOE | SOIL_TILLED | ACTION_TOO_LATE, INSUFFICIENT_STAMINA |
| Tilled, no crop | SEEDS | CROP_PLANTED | NO_SELECTED_SEEDS, time/stamina |
| Immature planted crop | WATERING_CAN | CROP_WATERED | ALREADY_WATERED, RAIN_WATERS_CROPS, time/stamina |
| Mature planted crop | HANDS | CROP_HARVESTED | time/stamina |
| Non-farm cell | no action | — | NO_TARGET / NOT_FARM_CELL, as today |

Resolve *which* action to use from the tile before asking whether that action can succeed. Thus already-watered/rainy crops still resolve to Water and display the truthful reason they cannot be worked. The mature state wins over Water, even if watered. Seed depletion must never make a tilled cell turn back into Hoe.

## Domain / command contract

Add **one** private GameSession action resolver, e.g. _action_for_target(target_cell: Variant) -> Variant (a FarmingAction integer, or null for non-farm). Read the authoritative _farm tile and GameRules.is_mature(); do not cache action in GameSession or persist it.

Rename `preview_selected_action(target_cell)` / `apply_selected_action(target_cell)` to `preview_target_action(target_cell)` / `apply_target_action(target_cell)` throughout production and tests, with no compatibility shims. Both obtain the action from the same resolver. Preview returns the same four keys (code, action, crop, cost), with action=null, crop=null and cost={} on a non-farm/missing target. Preview uses existing _hoe_failure/_plant_failure/_water_failure/_harvest_failure, _cost_for() and existing CommandCode success values. The action-specific command still owns mutation and budget checks; do not duplicate farming mutations or build a new command framework. Keep the active-day/finale guard's precedence over target failures.

Remove _selected_action, select_action(), and the selected-action failure switch in GameSession. **Delete** `GameRules.ACTION_KEYS` and `GameRules.action_key()`, which exist only to encode the retired selected tool, and remove their test assertions in tests/unit/test_game_rules.gd. **Keep** the FarmingAction enum for costs and preview display. Delete now-unreachable CommandCode.ACTION_SELECTED, its HUD feedback/SFX arm, and test expectations; retain SEED_SELECTED and ACTION_SFX for seed cycling. Update all affected enum references in one coherent implementation checkpoint with no backward-compatibility shims.

For non-farm targets preserve NO_TARGET vs NOT_FARM_CELL and the current WorldShell interaction hints for shop, bed, shipping, villagers and market. Never invoke an action-specific failure checker with an invalid farm index.

## Held Space: lock action per gesture, not per cell

A **fresh** Space press binds WorldShell._action_hold_action to the targeted cell's resolved FarmingAction **before** dispatch when starting on a farm cell. Starting off-farm leaves the lock null *temporarily*: when an off-farm hold first targets a farm cell, bind to that tile's resolved action (even if blocked) after the existing target-change/dwell reset. This preserves today's path/fence-to-farm walk-in sweep without adding a visited-cell set. `_advance_action_hold()` still requires dwell and a success preview, plus `preview.action == _action_hold_action`. A just-tilled cell now previews Seeds, so a Hoe-locked gesture cannot plant it even after a full dwell. A gesture started on an already-watered/rainy valid farm tile locks Water, not another available action. Keep current just-worked-cell eligibility, target dwell and cancellation behavior; no queue or extra state owner.

Fresh release resets the held action and target/dwell values; seed changes, modal gates and focus loss cancel the gesture as before. Use a new `WorldShell.use_target_action()` one-shot wrapper and `_attempt_target_action()` command path; don't keep the old selected-action naming just for test fixtures. Both native Space and the E2E `call_method(WORLD, "use_target_action")` string invocation must use the renamed API. Test fresh farm start, blocked farm start, and an off-farm press walking onto the first work tile without releasing; all must preserve one action per held gesture.

## Persistence contract: intentional old-save rejection

Delete selected_action from GameSession.state(), snapshot(), restore_state() and all state/snapshot fixtures; continue persisting selected_seed. Remove the now-obsolete required selected_action check from SessionStateValidator.state_error() **without** adding a special retired-field rejection. Bump SaveFileCodec.SCHEMA_VERSION from 2 to **3**, keeping the existing envelope shape and mismatch rejection. Every persisted v2 save is rejected at SaveFileCodec.decode() before GameSession.restore_state() sees it; the normal SaveRepository → AppRoot path disables Continue and reports the current **"Save unavailable; start a New Game."** message. New Game remains playable. This does **not** prevent a test or internal caller from supplying an extra selected_action key directly to restore_state(), since the state validator does not ban arbitrary surplus fields; that is intentionally outside the production legacy-save contract.

Use existing codec-version mismatch tests to prove schema **2** is unsupported and schema **3** round-trips, and update all exact-version pins including tests/unit/test_game_session.gd's `test_schema_2_transport_...`, tests/integration/test_app_launch.gd and schema-v2 documentation. Build **test** envelopes using SaveFileCodec.SCHEMA_VERSION: current version for malformed state/vector-marker branches, -1 for legacy, +1 for future. This prevents the existing bad-vector tests (currently hardcoded to v1) from passing merely at the wrong-schema gate. Assert the intended errors, not only `ok == false`. Keep validator coverage for required fields such as selected_seed and atomic failed restore. No schema DSL, format migration, general strict-key check, SaveRepository rewrite, or backup behavior.
