## Proposed scope decisions

The older modal-mask tests conflict with the explicit menu Tab requirement. This plan enables tips only over ordinary phone menus and preserves masking for protected flows (including dialogue's existing Tab behavior), not a hidden-tip dismissal or universal overlay. The C1 board still shows uppercase Start Day and inline weather; the written ticket and original comparison determine the corrected behavior. Use the existing shared Continue key, including Japanese つづける. One fixed logical layout and natural-width segments; one local Calendar chip helper. No new MCP driver; use existing bridge/input path, keep MCP visual acceptance and independently verified real-key E2E. No asset generation or additional PRs.
